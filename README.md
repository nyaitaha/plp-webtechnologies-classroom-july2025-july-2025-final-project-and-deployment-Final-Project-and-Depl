# Streamix Web Application

Streamix is a simple movie streaming website mockup built with HTML, CSS, and JavaScript. It features a modern, responsive design and includes three main pages: Home, Movies, and Contact.

## Features

- **Home Page (`index.html`)**
  - Hero section with background image and call-to-action buttons.
  - Trending and Popular movies displayed in carousels.
  - Modal video player for movie trailers.
  - Responsive navigation and footer.

- **Movies Page (`movies.html`)**
  - Grid display of all movies.
  - Clickable movie cards open trailers in a modal.
  - Responsive layout.

- **Contact Page (`contact.html`)**
  - Contact form for user feedback.
  - Form validation and success message.
  - Clean, modern styling.

- **Styling (`styles.css`)**
  - Dark theme with accent colors.
  - Responsive design for mobile and desktop.
  - Styled buttons, forms, cards, and modals.

- **Functionality (`script.js`)**
  - Dynamic rendering of movie cards.
  - Modal logic for video playback.
  - Contact form handling.
  - Automatic year update in footers.

## How to Run

1. **Clone or download the project files.**
2. **Open `index.html` in your browser.**
3. **Navigate between pages using the navigation bar.**

No build tools or server setup required; all files are static.

## File Structure

- `index.html` — Home page
- `movies.html` — Movies listing page
- `contact.html` — Contact form page
- `styles.css` — Main stylesheet
- `script.js` — JavaScript for interactivity

## Customization

- **Add more movies:** Edit the `movies` array in `script.js`.
- **Change styles:** Modify `styles.css` for colors, fonts, or layout.
- **Update content:** Edit the HTML files for text and structure.
